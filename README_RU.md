# Dead Air — Тишина в эфире (Forge 1.20.1)

Это исходный проект первой версии атмосферного хоррор-мода.

## Что уже реализовано в исходниках
- Скрытая серверная шкала паранойи: темнота и одиночество повышают её.
- Редкие сообщения-шёпоты и текстовые помехи при высокой паранойе.
- Уведомление о полнолунии.
- После первой смерти или третьих игровых суток появляется на короткое время молчаливый наблюдатель вдали.
- Попытка сна при высокой паранойе ночью может вызвать пробуждение, короткое сообщение и небольшой урон.

## Важно: статус сборки
В этой среде нет Gradle и нет доступа к Maven/Forge-серверам, поэтому готовый `.jar` здесь не удалось собрать или проверить. ZIP содержит исходный проект, который нужно собрать локально. Я не выдаю его за готовый установленный мод.

## Сборка
1. Установи Java 17 (Minecraft Forge 1.20.1 использует Java 17).
2. Скачай Forge MDK для Minecraft 1.20.1 и Forge 47.x либо открой этот проект в IntelliJ IDEA с поддержкой Gradle.
3. В каталоге проекта запусти `gradle build` (если Gradle установлен).
4. Результат сборки появится в `build/libs/dead-air-1.0.0.jar`.
5. Положи JAR в папку `.minecraft/mods` и запусти профиль Forge 1.20.1.

## Ограничения первой версии
Это ранний прототип: у наблюдателя пока нет собственной модели/текстуры и продвинутого поведения «исчезает при взгляде»; звуковые эффекты, полноценные случайные структуры, визуальные CRT-помехи и настоящая анимация сна ещё не реализованы.
