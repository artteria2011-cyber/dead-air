# Как получить DeadAir.jar через GitHub Actions

1. Создайте аккаунт на https://github.com/ (если его ещё нет).
2. Нажмите `+` → `New repository`, задайте имя, например `DeadAir`, и создайте репозиторий.
3. На странице репозитория выберите `Add file` → `Upload files`.
4. Распакуйте этот ZIP на компьютере. Загрузите **содержимое папки `dead-air`**, включая скрытую папку `.github`, в корень репозитория. Убедитесь, что в корне видны `build.gradle`, `settings.gradle`, `src` и `.github`.
5. Нажмите `Commit changes`.
6. Откройте вкладку `Actions`, выберите workflow `Build Dead Air` и дождитесь зелёного статуса. Он может запуститься автоматически после загрузки файлов. Если нет — нажмите `Run workflow`.
7. Откройте успешный запуск. Внизу страницы найдите `Artifacts` и скачайте `DeadAir-Forge-1.20.1`.
8. Распакуйте скачанный artifact ZIP. Внутри будет `.jar`, который затем можно скопировать в папку `%appdata%\\.minecraft\\mods` при установленном Forge 1.20.1.

Если сборка завершится красным статусом, откройте её, раскройте шаг `Build mod` и скопируйте сюда последние строки ошибки. Не публикуйте токены или пароли.

Примечание: этот workflow автоматизирует компиляцию, но не гарантирует, что все игровые функции и рендеринг сущности полностью реализованы или проверены.
